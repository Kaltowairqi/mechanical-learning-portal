## Next session

Begin M1 by reviewing the actual editions/resources the learner can access. Define the structured schema and draft only the two pilot module specifications. Verify publisher/author/course sources before adding exact chapters/sections. Build a minimal migration and UI around those pilot fields, with no large-scale curriculum rewrite. The curriculum gap analysis is the intake checklist.

## Deferred deliberately

React/TypeScript, database migration, cloud hosting, public registration, multi-user roles, unrestricted binary uploads, full automatic grading, and physical flight-test execution are outside the baseline. Introduce a dependency only for a concrete requirement with a documented tradeoff.
